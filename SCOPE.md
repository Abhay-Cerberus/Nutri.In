## What's IN Scope

- **Single-dish photos** — one dish per image
- **25–30 Indian dishes** — selected by intersecting:
  - (a) Khana dataset's 80 classes
  - (b) Campus canteen/mess availability
  - (c) IFCT ingredient coverage
- **Macronutrients:** Calories, Protein, Carbohydrates, Fat
- **Web prototype** — photo upload → dish ID + grams + calories + range → chat refine
- **Benchmark:** GPT-4o and Gemini vs. our pipeline on identical test images
- **Released resources:** Recipe table + weighed test set documentation

## What's OUT of Scope

- Multi-item automatic segmentation (thalis with multiple dishes)
- Micronutrients (vitamins, minerals — IFCT supports it, but scope constraint)
- Regional recipe variants beyond one default per dish
- Drinks and beverages
- Packaged/processed foods
- Real-time video analysis
